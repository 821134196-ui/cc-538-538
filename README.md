# 公园树木认养系统（本地版）

公园开放部分树木供居民认养。居民提交申请、选择养护方式；园艺师制定浇水 / 修剪 /
病虫观察计划；认养人可查看真实执行记录与年度反馈。支付与通知均为**模拟适配器**，
照片存本地文件，计划与业务数据存 **SQLite**。仅依赖 Python 3.10+ 标准库。

## 一条命令启动

```bash
./run.sh          # 默认 http://127.0.0.1:8000
./run.sh 8128     # 指定端口
```

脚本会初始化 SQLite（`data/park.db`）、生成本地示例照片（`data/photos/`）、
预置演示数据（含 **T006 国槐移栽案例**、T004 雪松患病封控案例、待复核的虫害诊断
与居民枯萎误报），随后启动服务。浏览器打开提示的地址，登录页可一键切换身份：

| 账号 | 身份 | 说明 |
|---|---|---|
| `alice` / `bob` | 居民 | 提交认养、支付占位、查看自己树木的记录 / 年报、报告枯萎 |
| `chen` | 园艺师 | 制定计划、登记执行、提交异常诊断、核查居民报告 |
| `zhou` | 主管 | 复核异常诊断；确认后专业健康结论才会变更 |

## 功能页

- **树木地图** `/map`：SVG 标注树冠位置与步道；树冠颜色＝健康状态，外圈＝认养状态
  （蓝环已认养 / 黄虚环名额锁定或已预约），两状态分离。
- **树木详情** `/trees/<id>`：档案、认养状态与健康状态分开展示、养护记录按
  **春 / 夏 / 秋 / 冬** 排列、事件时间线、巡查照片、年度反馈。
- **认养申请** `/apply`：选树、期限、自助养护 / 委托园艺师；提交即占位，模拟支付。
- **我的认养** `/adoptions`：支付、退出；园方可见全部记录。
- **养护日历** `/calendar`：月历与任务列表，按类型着色，可登记执行。
- **异常复核** `/diagnoses`：园艺师诊断 → 主管；居民报告 → 园艺师现场核查。
- **年度反馈** `/reports`：园方编制，仅该树认养人可查看。
- **通知** `/notifications`：模拟通知适配器的站内收件箱。
- 园方在地图页点「运行每日巡检」：释放过期占位、把逾期任务标记并重排（+7 天）。

## 关键业务规则

1. **期限互斥**：同一棵树的认养区间为半开区间 `[start, end)`，重叠一律拒绝；
   待支付占位同样占名额。并发申请在 `BEGIN IMMEDIATE` 事务内按 `created_at`
   （提交时间）先到先得，见 `tests/test_mutex.py`。
2. **占位释放**：占位 15 分钟内未支付自动过期（`release_expired_holds`，
   申请事务内也会先清过期占位；支付瞬间再做一次 TTL 校验），名额立即释放并通知申请人。
3. **计划随事件更新**：
   - 移栽（主管确认）：原计划中止，安排第 7 / 14 天复壮观察，通知认养人；
   - 患病封控：暂停浇水 / 修剪，改为连续四周每周病虫观察；
   - 认养人退出：取消其未来任务，释放期限；
   - 任务逾期：标记「已逾期」并自动重排一次，通知认养人与园艺师；
   - 居民误报枯萎：核查正常后补一次浇水与一次复查。
4. **专业健康结论不可由认养人修改**：园艺师只可提交诊断（`待复核`），
   只有主管确认后才写入 `trees.health_status`；居民报告经园艺师核查属实的，
   会自动转为园艺师诊断再走主管复核。
5. **跨用户隐私**：认养单、任务、真实执行记录、巡查照片、年报均限本人或园方；
   树木档案照登录可见，巡查 / 执行照按树鉴权（防目录穿越）。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

26 个用例，分四组：

- `tests/test_mutex.py` — 期限互斥（边界相邻 / 重叠 / 占位阻挡）与 5 线程并发仅 1 个成功；
- `tests/test_hold_release.py` — TTL 释放、临界支付、支付他人占位被拒、退出后任务与期限释放；
- `tests/test_diagnosis.py` — 园艺师不能自审、主管确认才改健康结论、移栽 / 封控 / 误报联动、
  居民报告属实升级主管；
- `tests/test_privacy.py` / `tests/test_http_privacy.py` — 服务层与 HTTP 层跨用户 403、
  照片访问控制、未登录跳转。

## 目录结构

```
app/
  database.py   SQLite schema 与连接（外键开启、WAL）
  adapters.py   模拟支付 / 通知适配器、可注入时钟（FakeClock）
  services.py   领域规则：互斥、占位、计划联动、异常复核、年报、权限
  web.py        http.server 路由与页面（SVG 地图 / 日历 / 上传）
  seed.py       预置数据（含移栽案例，SVG 照片本地生成）
  main.py       启动入口
run.sh          一条命令
tests/          unittest 测试
data/           运行时生成（park.db、photos/），不入库
```
